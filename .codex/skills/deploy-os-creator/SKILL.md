# Deploy OS Creator

Создать или восстановить одно приватное, версионируемое состояние оператора.
Сначала искать действующий инвентарь, vault и проверяемые копии: найденный
владелец состояния определяет контур восстановления.

Прочитать [процесс создания](references/create-state.md). Использовать этот
навык для нового состояния или восстановления. Текущие операции выполнять
через `$deploy-os` с явным `DEPLOY_OS_ROOT`.

Работа в локальном репозитории следует запросу оператора. Создание облачных
ресурсов, перенос секретов, публикация и изменения работающих систем требуют
разрешения на соответствующие системы в текущей задаче.

Завершение включает локальную проверку первого потребителя, проверяемый restore,
актуальную документацию и подтверждение обязательных копий. Live-приёмку
указывать отдельно согласно фактически выполненным действиям.
