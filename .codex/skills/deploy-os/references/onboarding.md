# Подключение проекта

Сначала подтвердить один авторитетный private state root и владельца проекта.
Проверить действующие инвентарь, vault и резервные копии перед созданием записи.

1. Выбрать стабильный project_id в kebab-case. В корне Git-проекта записать
   `.ops-project`: `project=<id>` и `contract_version=1`.
2. В приватном `docs/projects.md` зарегистрировать существующие потребители.
3. При наличии deploy создать `projects/<id>/operations.sh` с plan, inspect,
   backup, deploy, smoke и rollback. Plan показывает действия без записи.
   Скрипт получает `VPS_OPS_ROOT`, `VPS_OPS_SOURCE_DIR` и `VPS_OPS_PROJECT`.
4. При наличии секретов зарегистрировать их каталог, SOPS-копии и реплики.
   Проверить restore через независимый способ расшифрования.
5. Проверить resolver из вложенного каталога приложения, plan и безопасные
   локальные проверки. Запись на реальные хосты выполнять в разрешённой области.

Примеры `examples/` синтетические; их копирование не подключает реальный хост.
