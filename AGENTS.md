# Работа с Deploy OS

Этот репозиторий владеет общими инструментами и навыками. Состояние оператора
находится в отдельном приватном checkout, который задаёт `DEPLOY_OS_ROOT`.

Хранить здесь код, синтетические примеры и общие инструкции. Любые реальные
каталоги секретов, зашифрованные контейнеры, recovery, SSH-адреса, инвентарь,
имена клиентов, журналы и рабочие receipts принадлежат приватному состоянию.
Граница публикации задаётся `public-files.txt`; новые файлы требуют явного
добавления и ревью. Никогда не копировать историю приватного репозитория.

Перед изменением работающих систем прочитать инструкции выбранного private
state root, создать нужные backup, определить rollback и проверить результат.
Локальные тесты используют синтетические каталоги и временные ключи.
Shell: POSIX sh, set -eu, отступ 2 пробела. Документация: русский язык.

Проверка перед коммитом:

```sh
python3 -B -m unittest discover -s tests < /dev/null
python3 -B scripts/check-public-tree.py
python3 -B scripts/check-public-tree.py --history
git diff --check
```

Public safety gate проверяет рабочие, staged и tracked файлы; режим `--history`
проверяет все доступные commit snapshots и ref/tag names. Диагностика содержит
только код правила, путь и номер строки. Совпавшие данные не выводятся.
Выпуск обновляется через PR и CI по [процессу](docs/releasing.md).
